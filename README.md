# 🏥 Prescripto – Doctor Appointment Booking Platform

A full-stack healthcare appointment booking platform built using the MERN stack that enables patients to book appointments with doctors while providing a secure admin dashboard for doctor and appointment management.

---

# 🔍 Problem Statement

Traditional healthcare appointment systems often suffer from:

* Manual appointment scheduling
* Poor doctor discovery experience
* Lack of centralized appointment management
* Inefficient patient-doctor coordination

As a result:

* Booking appointments becomes time-consuming ❌
* Patients struggle to find relevant doctors ❌
* Clinics lack streamlined management systems ❌

---

# 💡 Solution Overview

Prescripto provides a modern healthcare platform that:

* Allows patients to browse and book doctors online
* Enables secure admin-based doctor management
* Supports image uploads and dynamic doctor listings
* Provides scalable backend APIs for healthcare workflows

The system combines full-stack web technologies with secure authentication and cloud-based media handling.

---

# ⚙️ How It Works

1. Admin logs into dashboard
2. Doctors are added with profile images
3. Doctor data is stored in MongoDB
4. Patients browse doctors by specialization
5. Users select appointment slots
6. Appointment workflow is handled through REST APIs

# 🚀 Getting Started

## Prerequisites

* Node.js
* MongoDB Atlas
* Cloudinary Account

---

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/prescripto.git
cd prescripto
```

### Backend

```bash
cd backend
npm install
npm run server
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Admin Panel

```bash
cd admin
npm install
npm run dev
```
